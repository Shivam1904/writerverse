# Legacy Components

This directory is **legacy**. Do not add new components here.

All active UI work lives in `frontend/src/app/`. The components here are kept alive only because they are referenced by routes not yet moved into `app/`.

## Styling note

Any styling guidance in this directory predates the current rules. The current rules (in `CLAUDE.md`) apply: no CSS file creation, layout via Tailwind classes, visual styles via Shadcn kit components at `frontend/src/app/ui/`.
